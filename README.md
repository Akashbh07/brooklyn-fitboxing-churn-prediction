
# Brooklyn Fitboxing: Predicting Member Churn

This project is developed as part of the individual coursework for the module **M516 Business Project in Big Data & AI** at Gisma University of Applied Sciences. It implements an end-to-end machine learning pipeline to predict member churn at Brooklyn Fitboxing, enabling management to proactively identify at-risk members and deploy targeted retention strategies.

## Project Structure
- `fitboxing_churn_dataset.csv`: The dataset containing member demographics, attendance metrics, and behavior trends.
- `M516_Final.ipynb`: The main Jupyter Notebook containing EDA, preprocessing, model training, evaluation, and risk scoring.
- `README.md`: Project documentation and setup guide.
